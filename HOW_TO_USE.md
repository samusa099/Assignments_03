# 📘 How, Where & Why to Use This Project

## Project
**Bangladesh Flag & Social Icons — CSS Practice**

## Why Use It

This repository is a focused exercise for learning CSS shapes, positioning, colour selection, image assets, social icons, and basic page structure without a build process.

Use it to:

- Practise creating simple graphics with CSS
- Learn relative and absolute positioning
- Review image-based and Font Awesome icons
- Demonstrate early HTML/CSS learning progress
- Experiment with spacing, lists, and colour contrast

## Where It Can Be Used

- Beginner HTML/CSS assignments
- Front-end training demonstrations
- CSS positioning practice
- Small national-theme UI experiments
- Classroom examples of asset and icon integration

> Do not use placeholder social links as real links. Review flag proportions and accessibility before publishing a production version.

## How to Use It

```bash
git clone https://github.com/samusa099/Assignments_03.git
cd Assignments_03
```

Open `index.html` directly in a browser or use **VS Code Live Server**.

### Customisation Steps

1. Review the flag structure in `index.html`.
2. Edit dimensions, positioning, and colours in `css/style.css`.
3. Replace social images in `images/` if required.
4. Update every placeholder `href="#"` with a valid destination.
5. Test icon spacing and keyboard accessibility.

## File Guide

| File or Folder | Purpose |
|---|---|
| `index.html` | Flag markup, social images, and icon-list structure |
| `css/style.css` | Shape, position, colour, size, and icon styling |
| `css/font-awesome.min.css` | Local icon library stylesheet |
| `images/` | Social-media image assets |
| `README.md` | Project overview and quick-start guide |
| `HOW_TO_USE.md` | Detailed usage and learning guide |

## Recommended Workflow

1. Open the existing output.
2. Identify which CSS rule controls each visible element.
3. Change one dimension or position at a time.
4. Test the design on different screen widths.
5. Replace placeholders and add accessible labels.
6. Validate HTML and CSS before publishing.

## Suitable Practice Tasks

- Rebuild the flag using modern CSS layout
- Centre the red circle more accurately
- Convert image icons to accessible links
- Add hover and focus states
- Make the composition responsive
- Create a reusable social-icon component

## Limitations

- Static demonstration only
- Social links are placeholders
- The layout may require additional responsive rules
- Image assets should be verified before redistribution
