## 📌 Overview

A compact HTML and CSS exercise recreating the Bangladesh flag and arranging social-media icons with image assets and Font Awesome.

The repository is organised as a self-contained project that can be downloaded, reviewed, and run locally with minimal setup.

---

## ✨ Key Features

- ✅ Bangladesh flag constructed with CSS shapes
- ✅ Image-based social sharing icons
- ✅ Font Awesome social icon list
- ✅ Positioning, spacing, and color practice
- ✅ Simple browser-ready project with no build process

---

## 🛠️ Technology Stack

| Technology | Purpose |
|---|---|
| **HTML5** | Page structure and semantic content |
| **CSS3** | Layout, typography, responsiveness, and visual styling |
| **Font Awesome** | Interface and social icons |

```bash

```

Open `index.html` directly in a modern browser, or use the **Live Server** extension in Visual Studio Code for automatic refresh.
